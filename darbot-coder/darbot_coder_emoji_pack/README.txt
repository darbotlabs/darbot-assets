# Darbot Coder Emoji – Asset Pack

This pack contains production-ready emoji assets for **darbot coder** in three variants:

- **transparent**: Neon style with preserved glow, transparent background. Best for modern apps with dark or light UI.
- **flat**: Small-size-optimized solid green (no glow). Crisp at 18–32 px. Use this for Slack/Discord/GitHub custom emoji.
- **blackbg**: Marketing version on black with glow, for banners or hero cards.

## Recommended usage
- **Slack custom emoji**: Upload `darbot-coder-emoji_flat_128.png` or `darbot-coder-emoji_flat_64.png` (≤256 KB).
- **Discord custom emoji**: Use `darbot-coder-emoji_flat_128.png` (static). Nitro allows larger; standard limit is ≤256 KB.
- **GitHub org emoji** (gh-emoji via markdown in repos or discussions): Use transparent 64–128 px variants.
- **Microsoft Teams custom emojis**: Use 32–128 px. Prefer `flat`.
- **iMessage/Telegram stickers**: Use 512–1024 px transparent variant. Telegram supports .webm/.tgs, but static PNG is fine to start.
- **Windows/Mac app icon**: Use `darbot-coder-emoji_flat.ico` (multi-size) for Windows; PNGs for macOS asset catalogs.

## Color
- Primary: Terminal green `#00FF78` (approx).

## Naming conventions
`darbot-coder-emoji_<variant>_<size>.png`

## Notes
- The **flat** set is tuned for legibility at 18 px. If your platform renders smaller than 18 px, consider fallbacks at 20–24 px.
- Avoid backgrounds for emoji uploads; use transparent or flat versions.
