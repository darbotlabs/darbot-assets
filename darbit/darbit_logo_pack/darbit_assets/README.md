# Darbit logo asset pack

This pack contains the **darbit** icon based on the provided robot baseline, with the **Darbot visor geometry** swapped in.

## What's inside

- `svg/darbit_master.svg` — rich gradients (core icon)
- `svg/darbit_flatsteps.svg` — banded gradients (crisper + smaller)
- `svg/darbit_mono.svg` — monochrome outline

- `png/master/` — transparent PNGs at 16..2048
- `png/flatsteps/` — transparent PNGs at 16..2048
- `png/mono/` — transparent PNGs at 16..2048

- `platform/vscode/icon.png` — 128×128
- `platform/swagger/favicon.ico` — 16/32/48
- `platform/swagger/Darbit.ico` — 16..256
- `platform/pwa/apple-touch-icon.png` — 180×180
- `platform/pwa/android-chrome-192x192.png`
- `platform/pwa/android-chrome-512x512.png`
- `platform/docs/og-image_1200x630.png`

## Notes

- No filters/blur; gradients only.
- Visor path data was kept verbatim (only scaled/positioned).
